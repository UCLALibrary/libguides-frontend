# UCLA Library LibGuides Frontend

Source of truth for UCLA Library's LibGuides frontend customization code, including HTML templates, CSS, and related assets.

## Project Goals

- Preserve the existing Bootstrap 3 implementation.
- Migrate frontend customizations to Bootstrap 5.
- Maintain source code in GitHub.
- Build and host CSS externally.
- Test changes using Springshare's Bootstrap 5 Transition Tool.

## Development

Development setup and deployment instructions will be added as the project progresses.
