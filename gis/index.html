Quick Start

  • EVGeoCloud This link opens in a new window
    • This link opens in a new window

    A web-based platform that provides online access to geospatial data, hosting many terabytes of vector data, raster data, and digital maps. To access this database, select the link for UCLA; you must also be using a computer that is connected to your UC campus network. The VPN must be used for off-campus access to this resource.

  • PolicyMap This link opens in a new window
    • This link opens in a new window

    Online data and mapping application with access to more than 10,000 indicators for U.S. demographics, housing and real estate, income, mortgages, health, and more. Create custom maps, tables, and reports and upload your own data without expensive software and training. Online access restricted to UCLA.

  • SimplyAnalytics This link opens in a new window
    • This link opens in a new window
    SimplyMap is a web-based mapping application that lets users quickly create professional-quality thematic maps and reports using demographic, business, and marketing data for the United States. Licensed for use by 5 simultaneous users. Your work can only be saved if you make an account. However, you can still use the application as a guest.
  • Social Explorer This link opens in a new window
    • This link opens in a new window
    Current and historical demographic and social data, plus online tools to create custom maps and reports. Optional personal login account required to save and share projects online.
  • California Geographic Information Association This link opens in a new window
  • EarthWorks This link opens in a new window
    Stanford's EarthWorks allows you to search the digital data and scanned map libraries of several different institutions.

  • GeoBlacklight Project Showcase This link opens in a new window
  • David Rumsey Map Collection This link opens in a new window
    Geo-reference maps
  • GISDegree.org This link opens in a new window
    Streamline your search for the best GIS degrees & certificate programs in the USA with GISDegree.org. Browse by state or dig into our comprehensive listings of on-campus and online programs in GIS and Geographic Information Science (GIScience). You’ll find everything from associate’s degrees to PhD programs. Or use the GIS career resources section to get a handle on certifications & networking.
