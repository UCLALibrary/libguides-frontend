Welcome to the Japanese Studies Library Research Guide (LibGuide)

The Japanese Studies library guide is your one-stop shop to finding research/scholarly resources related to Japan. You can find us on the second floor of YRL in the East Asian Library. Feel free to book a research consultation if you need help. 

  • Tomoko Bialock, Japanese Studies Librarian
  • Su Chen, East Asian Studies Librarian and Richard C. Rudolph East Asian Library Head
  • Junko Tanaka, Japanese Acquisitions and Cataloging Specialist

    • This link opens in a new window

  • Nichigai MagazinePlus This link opens in a new window
    • This link opens in a new window
    Article index - Article index for magazines. Search articles in magazines published in Japan from the Meiji period to the present. The database contains 45,889 journals and 20.36 million items from general journals, specialized journals, university bulletins, local journals, and foreign journals.
  • Nichigai WhoPlus This link opens in a new window
    • This link opens in a new window
    Biographical dictionary - Who's Who for Japanese and non-Japanese from ancient times to the present. Search profiles of over 800,000 famous peoples of various sectors both within and outside Japan. Includes 320,000 Japanese and non-Japanese, from historical figures to those currently active.

Japanese Information Literacy 

  • Japanese Information Literacy for Undergrads Full Course - Suzanne Fessler (University at Albany) This link opens in a new window
    An indispensable guide-- full Japanese Information Literary course. Includes information on everything from citing Japanese sources, Japanese eras/periodization, auspicious days, units of measure, noble titles/ranks, and subject-based resources. Please view (https://guides.nccjapan.org/infolitforundergrads) for syllabus and full course materials.

    Information on romanization standards, dictionaries, translations, references and resources by subject.

Romanization and Kanji

  • Japanese Romanization Table (2022) This link opens in a new window
    The ALA-LC Romanization table for Japanese in Modified Hepburn Romanization (Roma-ji system) is used in the English library databases. (ALA: the American Library Association アメリカ図書館協会, LC: the Library of Congress アメリカ議会図書館)
  • Simplified Roman-Kana chart This link opens in a new window
    A simplified Roman-Kana chart of 112 Japanese syllables including voiced and diphthong sounds.

  • 東文研ー異体字リスト List of variant kanji This link opens in a new window
  • 新旧字体変換用辞書 Converting Variant Kanji (List) This link opens in a new window
  • Digital Dictionary of Buddhism 電子佛教辭典 This link opens in a new window
    A dictionary of Buddhist terminology developed by user contributions and maintained by A. Charles Muller, professor of the University of Tokyo. Buddhist terms are indexed by radicals, texts, temples, schools, places, etc. Includes links to other useful Buddhist web resources.
    A list of lexicographical and canonical references used in DDB: http://www.buddhism-dict.net/ddb/references.html
    more... less...
    * Any user may access the dictionary by entering "guest" as the username with no password. This will allow a total of 20 searches in each of the DDB and CJKV-E dictionaries in a 24-hour period.
    Access via VPN to conduct more searches.

If you are new to accessing library materials, there is a world of information awaiting you. Here are some resources to get you started.

  • Classification (Library of Congress) This link opens in a new window
    Everything in most U.S. based academic libraries are sorted by the Library of Congress organization system. This link is a brief overview of each of the subjects.
  • Interlibrary Loan (ILL) This link opens in a new window
    Instructions for making an interlibrary loan request for materials not located at UCLA.
  • SLF-S (Systemwide Library Facility - South) This link opens in a new window
    Instructions for requesting materials stored at SLF (off-site storage facility).
  • Purchase Requests This link opens in a new window
    Submit a purchase request to have the library buy unavailable materials for you.
  • Navigating the Library and Library System (May 9, 2026)
    A six-page PDF document about finding books using the library system with a few exercises and an introduction to the other databases.
  • Using the Library - Student Resources This link opens in a new window
    General reference page for many library resources such as copy/scan, purchase requests, document delivery, etc.
  • Research Workshops This link opens in a new window
    No clue where to start? Research workshops cover everything from getting started with research, writing literature reviews, organizing data with spreadsheets or databases, finding sources at the UCLA Library, and more!
  • Studying & Learning Spaces This link opens in a new window
    Need somewhere to study? Try booking a room in any of our library spaces.
  • Print, Copy & Scan This link opens in a new window
    Our campus libraries offer self-service print, copy, and scan services.
